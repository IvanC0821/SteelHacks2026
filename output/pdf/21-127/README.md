# Fictional 21-127 upload samples

These are original practice questions, not copied official homework. Two homeworks have
five questions each. Each PDF student submission has exactly five pages: map page 1 to
q1, page 2 to q2, and so on. Upload a **student PDF**, not the questions handout.

The current app accepts PDFs only. Matching `.tex` files are editable source companions;
they contain the same student arguments. Compile locally (for example with pdflatex) if
you edit them. The supplied PDFs were rendered directly with ReportLab for embedded,
extractable text; their typography is not a TeX compiler's output.

## Files and intended controls

- `21-127-hw1-student-a`: correct work, including a harmless detour in the rationality proof.
- `21-127-hw1-student-b`: omits 27 in the set, misuses the prime-divisor property for 10,
  skips the specifically requested definition proof, extrapolates parity from examples,
  and proves only one set containment.
- `21-127-hw2-student-a`: correct proofs and a clear counterexample; no intended deductions.
- `21-127-hw2-student-b`: misses reachability of negative even integers, gives an inconsistent
  card assignment, and uses an invalid gap-count argument. Questions 2 and 4 are correct;
  the extra discussion in Question 4 should not attract a deduction.

These labels and expected issues are author notes, not a model grading guarantee. Student
PDFs use neutral A/B labels without embedding an answer key. New checks use the currently
configured model and may incur OpenRouter charges; generating these files does not.

The question sheets are included in this bundle. Staff reference solutions are deliberately
excluded from the bundle and from frontend static assets; the course setup attaches them
through the backend's staff-only document path.
