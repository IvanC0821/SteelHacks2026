# Task 6: fictional handwriting-style homework PDFs

Owns `tools/fixtures/**` (repo root) and may edit `tools/seed_dev.py` only to load files from `tools/fixtures/out/` when they exist (fall back to the current typed writer otherwise). Nothing in `frontend/`.

## Why

The seeded PDFs are typed Helvetica lines. The product is about handwritten math homework, so the demo paper should look like a scanned handwritten page: ruled or blank paper, a handwriting typeface, uneven baselines, matrices drawn with brackets, crossed-out slips, a margin. It must still be a real text PDF (the backend's pypdf extraction needs page text to anchor flags), fictional throughout, and small (< 300 KB per file).

## Build

- `tools/fixtures/make.mjs` (Node, Playwright already installed in `frontend/node_modules`; run it with `node --experimental-default-type=module` or plain ESM from `frontend/` as cwd so `playwright` resolves, or add a tiny `tools/fixtures/package.json` that depends on nothing and resolve playwright via `createRequire` from `frontend/node_modules`). It renders HTML pages to PDF with `page.pdf({ format: "Letter", printBackground: true })`.
- Typeface: install an OFL handwriting font into `frontend/node_modules` via `npm i -D @fontsource/caveat @fontsource/patrick-hand` (both OFL) and embed with `@font-face` from the file path; use two different fonts and slight per-line rotation/offset per student so students do not look identical. Math: matrices as bracketed HTML tables, arrows as text, fractions stacked.
- Content: exactly the fictional Homework 1 from `tools/seed_dev.py` (four questions: solve the system, rank and nullity, subspace proof, inverse). Produce: `questions.pdf` (typed, clean: this is the instructor's blank assignment), `solution.pdf` (typed, clean, labeled "Instructor solution"), and for each of the six students in `STUDENTS` a `v1.pdf` and, where versions == 2, a `v2.pdf`, three pages each: page 1 Q1 and Q2, page 2 Q3, page 3 Q4. Keep the mathematical content of each version the same as the current writer (v1 has unlabeled row operations, a list instead of a column vector, a proof by example, no verification; v2 fixes those), with small per-student variations (one arithmetic slip for two of the students, one crossed-out line). Every page has a header line "<Student name> · Homework 1 · page n of 3 (fictional)".
- The text layer must be extractable: check with `PYTHONPATH=backend .venv/bin/python -c "from pypdf import PdfReader; ..."` from the repo root that every page returns non-empty text.
- `tools/seed_dev.py`: add a loader that, if `tools/fixtures/out/<slug>-v1.pdf` exists, uploads that instead of the generated bytes (slug = first name lowercased); same for `questions.pdf` and `solution.pdf`. Keep the typed fallback. Do not change anything else in the seed.

## Proof

Render each PDF's first page to PNG (Playwright can screenshot the HTML before printing; or `pdftoppm` if present) into `tools/fixtures/preview/` and look at them with the Read tool; they should read as handwritten homework at a glance. Then, from the repo root, restart nothing: run the reseed (`PYTHONPATH=backend:. .venv/bin/python -m tools.seed_dev`) against the running backend on 8026 (it creates a new course; that is fine, the frontend lists the latest) and confirm the seed still completes and `frontend/.dev/session.json` is rewritten. Report file sizes, the extraction check output, and preview paths.
